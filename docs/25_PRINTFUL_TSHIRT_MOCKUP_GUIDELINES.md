# Printful T-shirt mockup sizing and placement

The storefront product images use one consistent black-shirt mockup on an ash-charcoal background. The displayed print size is derived from the **actual production artwork dimensions**, not from a visually enlarged marketing treatment.

## Printful guidance used

Printful's current guidance says:

- DTG artwork should generally be supplied as a transparent PNG when transparency is required.
- Print files should be high-resolution and sized for the actual intended print dimensions; Printful cautions against enlarging a smaller source just to fill a template.
- Most apparel requires at least 150 DPI; 300 DPI is acceptable and can preserve fine details.
- Product-specific File guidelines and safe zones remain authoritative.
- For select DTG shirts, the current standard large front area is **15 x 18 inches** and the Catalog API placement name for new products is **large_front**.
- Some smaller garment sizes use a reduced maximum area (Printful gives 11.5 x 13.8 inches as an example) and the artwork may be proportionally downscaled rather than cropped.
- Important text and graphics should stay inside the Design Maker's safe area.
- Dark garments receive a white underbase, which can alter appearance; physical samples remain the final color/print reference.

## Black Metal Buddha mockup decision

All four production raster files are **3600 x 4800 at 300 DPI**, which is exactly **12 x 16 inches**.

The storefront mockups therefore:

1. use the existing approved production PNG without enlarging it;
2. show a 12 x 16 inch front-print footprint on a generic adult black T-shirt;
3. center the design in the front print zone;
4. use the brand's ash-charcoal family instead of a white background;
5. use the same garment and camera framing for every product.

The mockup is a marketing visualization, not a guarantee of millimeter-identical placement on every size. Printful product templates and variant-specific downscaling remain authoritative. Once the final blank and variants are frozen, Printful-generated product mockups can replace or supplement these images if desired.
